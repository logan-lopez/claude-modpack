# Guide

How the pack works as you use it. One page per thing you do.

- [Playing the pack](playing.md): Prism Launcher kept in sync with the repo, or a `.mrpack`
  import, what to do when the instance won't launch, and looking after a world.
- [Running a server](server.md): building the server zip, its first start, settings, updating
  it, and what it doesn't do.
- [What's in the pack](mods.md): the mods by what they're for, and what was left behind from the
  old 1.20.1 pack and why.
- [Where guns come from](guns.md): the TaCZ gun packs and which table makes each, crafting guns
  through Create, chest loot, turrets, durability and the ammo box.
- [Fighting up close](combat.md): Better Combat's swings and combos, which weapons get them, and
  Combat Roll's dodge.
- [The quest book](quests.md): opening it, the sample chapter, editing in the game and bringing
  the edits back into the repo with `scripts/pull-quests.sh`.
