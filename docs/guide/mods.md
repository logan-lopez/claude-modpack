# What's in the pack

The mods the pack ships, grouped by what they're for, and the mods from the old 1.20.1 pack that
didn't come over, with why. Compare it with the old list (`docs/briefs/assets/02/old-modlist.txt`)
to decide what to add back.

**Covers:** `pack/mods/`

251 entries in `pack/mods/`: about 200 picked from the old pack, the rest libraries they need.
The server loads 232 jars; the other 19 are client-only (Sodium, Iris, the tooltip and overlay
mods, and the like).

## Known rough edges

- **Small Ships throws an error when the server stops,** while unloading its server config. A
  dedicated server has already saved by then. On a single-player world the same unload happens
  at Save and Quit, so if leaving a world crashes, Small Ships is the first suspect.
- **Apotheosis Modern Ragnarok's Brawler's gems** have gun bonuses whose categories overlap, and
  Apotheosis skips the ones that clash, so those gems may do less on guns than you'd expect.
